Use the `write-plan` skill (load it with `load_skill`) to plan this task:

$ARGUMENTS

Read the code the task touches before you plan, and name real files and functions. Change no code while planning.
If the task is unclear or has two sensible designs, ask one short question first. End with the plan in the skill's
format and ask whether to go ahead; build nothing until the user agrees.
